# Etapa 6 — comparação visual sintética

As capturas usam dados sintéticos e não contêm informação de clientes.

- `antes-mobile.png`: reconstrução visual do layout anterior a partir do código da versão ativa `eeadc03`. O gráfico foi representado por um espaço reservado; não é uma captura da produção.
- `depois-mobile.png` e `depois-desktop.png`: componente `ProfessionalPerformance` real, renderizado num preview local com a resposta da consulta simulada. O browser verificou o gesto de toque no gráfico (data, ganhos e serviço do dia), os cartões na mesma faixa, os nomes completos e a ausência de overflow horizontal na página. A seleção das datas personalizadas foi verificada na primeira versão deste candidato.

O preview não executou consultas nem escritas remotas.
